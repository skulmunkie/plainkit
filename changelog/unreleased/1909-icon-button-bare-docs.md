The docs and the agent skills now say which `pk-button` variant is the bare icon button: `plain` has no border, `ghost` keeps its 1px border and `secondary` an accent one. The collapsed `pk-app-bar-search` button is already a plain (borderless) button, and `--pk-button-border` on the host is the documented way to give it a border.
