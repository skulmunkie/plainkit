`pk-specimen` draws a spacing, size, radius, shadow or layer token (`--space-4`, `--radius-md`, `--shadow-card`, `--z-sticky`) at its resolved value, with the token name and value as text; the kind is inferred from the token prefix, and a slotted label replaces the name. Colours stay with `pk-swatch`.
