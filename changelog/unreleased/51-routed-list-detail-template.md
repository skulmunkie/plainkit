The `routed-list-detail` template (`core/samples/templates/routed-list-detail/`): a routed list and detail on `pk-workspace`, the list in the main pane and the record in the aside, with `aside-open`, `active-pane`, `aside-label` and the open row all set from one route; a detail header built from `pk-toolbar`, a phone back arrow, and a cancelable `pk-pane-change` veto for a host that owns `active-pane`. Its notes carry the Blazor page skeleton, and the `plainkit-blazor` skill has the same page as a workflow. Template metas may carry `notes`, which the generated `templates.md` prints.
