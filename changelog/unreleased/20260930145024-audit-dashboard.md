Adds an audit dashboard devtools module (`core/modules/audit-dashboard/`, `mountAuditDashboard`) that browses the module-ruleset baseline (`plainkit.audit.modules.baseline.json`) as a filterable, sortable pk-dock workspace: a findings table grouped by file and rule id, and a Properties panel showing the full detail of the selected finding. It only ever reads the JSON already on disk (served by `core/tools/serve.mjs` under `/_audit/module-baseline.json`); it never regenerates it or shells out. UI review and conformance-audit panels are tracked as follow-up scope on issue #717.
