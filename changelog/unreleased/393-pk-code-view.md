New `pk-code-view` element (`PkCodeView` in Blazor): a read-only, line-numbered listing with a sticky gutter that a selection or
a copy leaves out, highlighted lines (`highlight="3, 5-7"`), a starting line number, per-line coloured segments and horizontal
scrolling. The code explorer's viewer is now this element, so other pages can show code the same way.
