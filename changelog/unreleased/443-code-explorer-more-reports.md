`pk-code-explorer`'s Reports tab gains three built-in reports, always available with no host setup: largest files, longest methods (a brace-matching heuristic for C#, JS and similar languages) and duplicate blocks (runs of 4+ identical consecutive lines found in 2 or more places). Host-defined patterns now show as one more choice, "Patterns", in the same picker.
