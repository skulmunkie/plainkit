`PkRawTable` composes a `HeadContent`/`ChildContent`/`FootContent` table into `pk-table`'s raw slot, with the same appearance and scroll-frame parameters (`Striped`, `Hover`, `Bordered`, `Density`, `StickyHeader`, `StickyColumn`, `MaxHeight`, `Caption`, `Label`, `Flow`, `ToolbarContent`, `CaptionContent`, `FooterContent`) as `PkTable<TItem>`.
