## `pk-back-to-top`

**Back to top** (Navigation). A floating button that appears once the reader is well down the page and scrolls the page (or a named scroller) back to the top, smoothly unless reduced motion is on.

**Props** (set as an attribute in kebab-case, or as a property in camelCase; a boolean is present or absent)

| `label` | `label` | string | `"Back to top"` |  | Accessible name |
| `visible` | `visible` | boolean | `false` |  | Set by the element. |

**Slots** (`slot="name"` on a child)

| Slot | Description |
|---|---|
| (default) | Label. |

**CSS parts** (`::part(name)`)

| Part | Description |
|---|---|
| `button` | The button |
| `icon` | Kind icon |

**Accessibility.** A real button with a text label; after scrolling, focus moves to the top of the scroller so keyboard users are not left at the bottom.

Example: Back to top

```html

```

| `activation` | `activation` | enum | `"auto"` | `auto` `manual` | auto selects a tab when arrow keys focus it; manual moves focus and waits for Enter or Space. |
| `none-active` | `noneActive` | boolean | `false` |  | No tab is shown as selected, and choosing any tab (even the last one chosen) raises pk-tab-change. For a page whose cross-cutting view sits above its tabs. |
| `scroll` | `scroll` | boolean | `false` |  | One row that slides (touch swipe, wheel, drag) when the tabs outgrow the width, with a fade at the edge that has more tabs, instead of wrapping onto more rows. |

**Slots** (`slot="name"` on a child)

| Slot | Description |
|---|---|
| `tab` | pk-tab children (they assign themselves to this slot). |
| `panel` | pk-tab-panel children (they assign themselves to this slot). |
| `trailing` | Content inside the strip after the last tab: a hint, links or buttons. |

**Events** (`addEventListener`; `pk-*` events are CustomEvents whose `detail` is shown)

| Event | Detail | Description |
|---|---|---|
| `pk-tab-change` | `{ value, previous }` | A tab was chosen. Cancelable: preventDefault keeps the previous tab. |

**CSS parts** (`::part(name)`)

| Part | Description |
|---|---|
| `list` | The tab strip. |
| `panels` | The panel area. |

**Accessibility.** The strip has role=tablist; tabs and panels are related with aria-controls and aria-labelledby set on the light-DOM children (both live in the same tree, so the ids resolve). Roving tabindex: only the selected tab is in the Tab order (every tab when none is active); arrow keys move focus and skip hidden and disabled tabs.

Example: Tabs with panels

```html
<pk-tabs value="details">
  <pk-tab value="details">Details</pk-tab>
  <pk-tab value="history">History</pk-tab>
  <pk-tab-panel value="details">Item details.</pk-tab-panel>
  <pk-tab-panel value="history">Item history.</pk-tab-panel>
</pk-tabs>
```

Example: Scrolling strip with counts and trailing content

```html
<pk-tabs scroll value="a">
  <pk-tab value="a" count="12">Pending</pk-tab>
  <pk-tab value="b" count="3">Failed</pk-tab>
  <pk-tab value="c">Done</pk-tab>
  <span slot="trailing">Updated a minute ago</span>
</pk-tabs>
```

## `pk-tree`

**Tree** (Navigation). An expandable hierarchy of tree items with roving focus, single selection and type-ahead, following the WAI-ARIA tree pattern.

**Props** (set as an attribute in kebab-case, or as a property in camelCase; a boolean is present or absent)

| Attribute | Property | Type | Default | Values | Description |
|---|---|---|---|---|---|
| `label` | `label` | string | `""` |  | Accessible name. |
| `selection` | `selection` | enum | `"single"` | `single` `none` | Selection mode. |
| `value` | `value` | string | `""` |  | The value (or label) of the selected item. |

**Slots** (`slot="name"` on a child)

| Slot | Description |
|---|---|
| (default) | Root pk-tree-item children. |

**Events** (`addEventListener`; `pk-*` events are CustomEvents whose `detail` is shown)

| Event | Detail | Description |
|---|---|---|
| `pk-select` | `{ id: string }` | An item was chosen (bubbles from the item). |
| `pk-toggle` | `{ id: string, expanded: bool }` | A branch opened or closed (bubbles from the item). |

**Methods**

| Method | Description |
|---|---|
| `flattenTree(nodes)` | Visible nodes with level and parent. |
| `treeKey(items, index, key)` | What a key does. |
| `typeahead(items, index, text)` | Next matching label. |

**Accessibility.** role=tree with treeitem, aria-expanded, aria-selected, aria-level, aria-setsize and aria-posinset. One tab stop; arrows and Home and End move; Right and Left expand and collapse or move to the child or parent; Enter and Space select; typing a letter jumps to the next label starting with it.

Example: Categories

