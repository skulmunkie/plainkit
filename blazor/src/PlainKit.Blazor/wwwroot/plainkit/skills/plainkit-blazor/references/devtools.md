# Dev tools and tool components

> Plainkit 0.1.0-alpha.1. Generated by scripts/build-skills.mjs from Components/*.razor and the C# sources. Do not edit: change the source and run the generator.

In the Development environment, `/_plainkit` serves the toolkit's own tools: the Gallery, Files and Scorecard workspaces, and the SDK's dev tools dock (`PkDevTools`: Console, Logs, Logging, Performance, Quality, Inspector, Theme, plus the Blazor and Components tabs of PlainKit.Blazor). Serve it elsewhere with `AddPlainKit(o => o.DevTools = true)`. The Files tab reads a folder on the server (`PkOptions.SourceRoot`), so it does not work in a browser-only app. Each tool is also a component you can place on a page of your own:

## `PkGallery`

| Parameter | Type | Description |
|---|---|---|
| `Kind` | `PkGalleryKind` | Values: All, Foundations, Controls, Elements, Layouts, Templates. What to show. All shows the controls when a group or control is named, otherwise everything. |
| `Group` | `string?` | One control group by name ("Forms & inputs") or slug. |
| `Control` | `string?` | One control, element or sample id, or a comma separated list ("button,input"). |
| `Theme` | `PkTheme` | Values: Auto, Dark, Light. The theme of the gallery and its samples. |
| `Width` | `PkWidth` | Values: Desktop, Phone. Render samples at desktop width or in a 375px phone frame. |
| `Filter` | `string?` | Search text: only controls whose name (or group) contains it are shown. |
| `Chrome` | `PkChrome` | Values: None, Full. None (the default) is content only, sized to fit; Full adds the nav, toolbar and inspector. |
| `Height` | `int` | A fixed height in pixels; 0 fits the content (chrome none) or uses the default (chrome full). |
| `Src` | `string?` | The address of the gallery's embed page. Defaults to the one shipped with PlainKit.Blazor. |
| `AdditionalAttributes` | `Dictionary<string, object>?` | Extra attributes for the element. |

## `PkDevTools`

| Parameter | Type | Description |
|---|---|---|
| `Mode` | `PkDevToolsMode` | Values: Dock, Inline. Dock (the default) floats over the page; Inline fills this component's element. |
| `Tab` | `string?` | The tab shown first (console, logs, logging, performance, quality, inspector, theme, blazor or blazor-components), and the one selected when this changes. |

| `Theme` | `PkTheme` | Values: Auto, Dark, Light. The theme of the tools themselves. |

## `PkStyles`

| Parameter | Type | Description |
|---|---|---|
| `Minified` | `bool` | The minified stylesheet (CssMin) instead of Css. Same rules. |
| `Versioned` | `bool` | Adds `?v=` and a content hash of the file (see Versioned), so a browser fetches the file again exactly when it changed. On by default. |
| `InHead` | `bool` | Render the link through `HeadContent` (into `HeadOutlet`) instead of in place. That puts it after the app's own stylesheets in the standard `App.razor`, so the toolkit's base layer overrides app rules of equal specificity: leave it off unless you know you want that. |
